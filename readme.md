# Function in JavaScript

This is my first JavaScript project where I learned how to create and call a function.

## What does this project do?

This project has a function called `level()` which takes a name as input and prints 4 different compliment lines for that person.

## How to Run

1. Open terminal in this folder
2. Run this command:

```bash
node script.js
## Code Example
function level(name) {
  console.log("hey, " + name + " you are nice!");
  console.log("hey, " + name + " you are good!");
  console.log("hey, " + name + " you are great!");
  console.log("hey, " + name + " you are greatest!");
}

level("virat kohli");
## Output
hey, virat kohli you are nice!
hey, virat kohli you are good!
hey, virat kohli you are great!
hey, virat kohli you are greatest!
